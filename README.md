Overview

This is a simple Stone Paper Scissors game developed using Python.
The game allows a user to play against the computer in a fun and interactive way.

🎯 Features
User vs Computer gameplay
Random choice generation by computer
Input validation
Instant result display (Win / Lose / Draw)
Simple and beginner-friendly logic
🛠️ Technologies Used
Python 3
random module
📂 Project Structure
stone-paper-scissors/
│
├── game.py        # Main Python file
└── README.md      # Project documentation
▶️ How to Run
Install Python (if not installed)
Clone or download this repository
Open terminal / command prompt
Navigate to project folder
Run the game:
python game.py
🎮 How to Play
Enter your choice:
stone
paper
scissors
Computer will randomly choose its move
Result will be displayed instantly
🧠 Game Logic
Stone beats Scissors
Scissors beats Paper
Paper beats Stone
Same choices = Draw
💡 Example Output
Enter your choice (stone/paper/scissors): stone  
Computer chose: paper  
Result: You Lose!
